# uTools 轮盘工具

Windows 上的 uTools 插件。拖动文件可唤出目录轮盘，快速复制或移动文件。拖动选中的文字可唤出文本轮盘，直接把文字设为定时提醒。「轮盘设置」用于管理常用目录、登录自启和提醒清单。

## 文件轮盘

在资源管理器或桌面拖起文件，按住左键停稳约半秒。轮盘出现后，悬停在目录上可逐级展开子目录。子目录过多时，把指针放在对应列上，滚轮每格滚动一个目录。默认拖到目标目录后松手复制。将文件放到圆心时，轮盘会保留这批文件，操作仍为复制。点击圆心可切换复制或移动，再点击目标目录执行。点击轮盘外或按 Esc 取消。下一次拖动默认复制。

复制或移动完这一批文件后，轮盘会打开目标文件夹，方便继续处理。

## 文本轮盘

在 uTools 中搜索「文本轮盘」，直接打开定时表单和提醒清单。也可以在「轮盘设置」点击「打开提醒」。通过文本匹配进入时，单行文本会填入提醒标题。

选中文字后，把已选中的文字拖起来并停稳约半秒。在支持向外拖出纯文本的应用中，会弹出文本轮盘。在圆心松手可暂存文字，轮盘会保持打开，再点击「提醒」即可。也可直接拖到「提醒」扇区松手。轮盘直接打开独立的提醒窗口并预填文本，可编辑内容和设置时间。选择时间并保存后，任务会出现在同一个提醒清单里。

提醒模块沿用原 TaskBell 的本机数据目录 %LOCALAPPDATA%\TaskBell 和 Windows 计划任务。首次进入内置提醒界面，确认旧任务可见后，可在 uTools 停用或移除独立 TaskBell 插件。请保留该数据目录和 TaskBell 计划任务，以便继续按时响铃。

## 本机试用

1. 在 uTools 开发者工具中新建 Windows 插件项目，选择本项目中 `plugin/plugin.json` 作为工程入口，安装开发模式。
2. 点击开发者工具的「打开」或搜索「轮盘设置」，然后点击「启动监听」。可用「添加文件夹」指定一个测试目标。
3. 用一个测试文件验证复制和取消。可选中多个文件一起拖。
4. 在「轮盘设置」勾选「登录 Windows 时启动」后，轮盘监听会在当前用户登录后自动运行。开发模式安装后，每次开机无需重新安装或打开开发者工具。也可以在开发者工具构建 `.upxs` 离线安装包用于安装。
5. 如需完全停用，先取消登录自启，再点「停止监听」。卸载插件前也可执行这两步。

文件轮盘第一层最多显示六个目录。在 uTools 搜索「文件轮盘」可打开常用目录；从文件匹配结果进入时，可对选中的文件执行复制或移动。手动目录优先，余位取自快速访问和本机的资源管理器访问统计。目录列表为空时轮盘等待产生可用目标。移动或复制前会检查同名文件或文件夹，以及明显的父子目录冲突。配置及目录访问统计保存在当前用户的 `%LOCALAPPDATA%\UToolsWheel`。

Windows 组件已编译为 `plugin/Wheel.exe`。修改 `native` 下面的源码后，可运行 `build.ps1` 重新编译。更新后，先停止旧组件，再启动新版。若使用登录自启，请关闭后重新开启，让启动快捷方式指向新版。
