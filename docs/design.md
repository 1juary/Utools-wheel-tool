# 首版设计与验收

Windows 组件检测资源管理器及桌面的文件拖动，显示轮盘并执行文件操作。uTools 插件管理启停、登录自启和手动目录。配置和访问统计保存在当前用户的本机目录。

按住左键移动至少 12 像素并停稳约 500 毫秒后，候选窗口等待系统文件拖入。文件轮盘第一层最多显示六个目录，手动目录优先，其余来自快速访问和本机访问记录。悬停目录可展开子目录，滚轮逐项浏览指针所在的列。

默认拖到目录松手复制。拖到圆心松手会保留文件，之后点击圆心才切换复制或移动，再点击目标目录执行。复制和移动由 Windows 文件操作界面负责。

文本轮盘只显示提醒。uTools 的「文件轮盘」「文本轮盘」「轮盘设置」分别进入目录操作、提醒和配置。

可验证组件编译、配置保存、目录排序、多层导航、逐列滚动及文件复制和移动。真实拖放和重新登录自启需在交互式 Windows 会话中验收。
